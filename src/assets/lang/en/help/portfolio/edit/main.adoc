= Portfolio Edit

This page explains how to create and edit a *portfolio*.

== Opening the editor

. Navigate to *Inventory > Portfolios*
. Select an existing portfolio or press _Create_
. The editor opens in the right panel

== Available actions

* *Save* : stores the portfolio definition
* *Builder* : assigns trading systems to the portfolio
* *Delete* : removes the portfolio (irreversible)

== Fields

|===
|Field |Description |Required

|Name |The unique name of the portfolio |Yes
|Description |A free-text description |No
|Currency |The base currency used for allocation |Yes
|===

NOTE: Changes are applied only after pressing the save button.
